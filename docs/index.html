SUI.css v3.0.0 Documentation

Bootstrap-grade interactive components + Tailwind-grade utility ergonomics, built on perceptual OKLCH colors, native CSS @layer cascade, and zero runtime dependencies.

Real 8-Layer @layer Cascade

Utilities always override components without !important, and your own unlayered CSS automatically overrides SUI.

Light Mode by Default

Plain HTML pages stay crisp light by default. Opt into data-theme="dark", "oled", or "auto" whenever you want.

Bootstrap 5 Component Parity

Offcanvas drawers, Popovers, Dismissible Alerts, Floating Labels, List Groups, Pagination, Responsive Navbar, Carousel, ScrollSpy, and Modal Tab focus traps.

Tailwind Utility Parity

Includes sui-ring-*, sui-divide-*, sui-space-y/x-*, sui-object-*, sui-aspect-*, gradients, and sm/md/lg/xl responsive utilities.

Installation & Quick Start

Include dist/sui.min.css in your page head—no build step required. Add dist/sui.min.js only if you use interactive components (modals, offcanvas, toasts, dropdowns, navbar toggle).

HTML — Quick Start (v3.0.0) 
<!-- 1. Core Stylesheet (Required) -->
<link rel="stylesheet" href="./dist/sui.min.css">

<!-- 2. Interactive Runtime (Optional) -->
<script src="./dist/sui.min.js"></script>

8-Layer @layer Cascade

Explicit cascade layers eliminate specificity wars across components, overlays, utilities, and your custom CSS.

1. reset→ 2. tokens→ 3. base→ 4. layout→ 5. components→ 6. overlays→ 7. animations→ 8. utilities→ Your Custom CSS

Modals, Offcanvas, Dropdowns, Popovers & Accordions

Every interactive overlay supports keyboard focus management, Escape dismissal, and ARIA state sync.

Actions
SUI.popover

Click outside or press Escape to dismiss.

Yes! All tokens, layouts, utilities, buttons, cards, forms, and responsive rules work with CSS only.

Opening focuses the first interactive control, Tab cycles inside the dialog, and Escape closes while restoring focus to the trigger button.

HTML — Modal & Offcanvas Triggers
<button class="sui-btn sui-btn-primary" data-sui-modal-target="myModal">Open Modal</button>
<button class="sui-btn sui-btn-secondary" data-sui-offcanvas-target="myDrawer">Open Drawer</button>

JavaScript API Reference (window.SUI)

Every interactive module is auto-initialized on load and exposed cleanly on window.SUI (v3.0.0).

ModuleMethods / AttributesDescription
SUI.theme.set(mode), .get(), .toggle()Switches data-theme (light/dark/oled) & persists to localStorage
SUI.modal.open(id), .close(id), [data-sui-modal-target]Stacked modals with Tab focus trap, Escape, and focus restoration
SUI.offcanvas.open(id), .close(id), [data-sui-offcanvas-target]Slide-over drawers (start/end/top/bottom) with backdrop & Escape
SUI.navbar.toggle(btn), .closeAll(), .sui-navbar-toggleMobile navbar collapse/expand with aria-expanded & Escape
SUI.dropdown.open(id), .close(id), [data-sui-dropdown-trigger]Outside-click & Escape-dismissible dropdown menus
SUI.popover.toggle(id), .closeAll(), [data-sui-popover-target]Interactive click-triggered floating popovers
SUI.toast.show({...}), .success(), .error(), .warning(), .info()Accessible aria-live="polite" toast notifications
SUI.alert.dismiss(el), [data-sui-dismiss="alert"]Smoothly removes dismissible alert banners
SUI.carousel.goTo(wrapper, idx), [data-sui-carousel-prev/next]Scroll-snap carousel navigation & dot sync
SUI.scrollspy[data-sui-scrollspy]Highlights active sidebar/nav links as sections scroll into view
SUI.clipboard.text(str), .element(sel), [data-sui-copy]One-click clipboard copy (also aliased as SUI.copy)
