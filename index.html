Design Tokens

Customize SUI.css to match your own design system.

:root {
  --sui-primary: oklch(60% 0.2 250);
  --sui-radius: 0.5rem;
  --sui-spacing: 1rem;
  --sui-font-family: system-ui, -apple-system, sans-serif;
}

Try SUI.css

Start Building in Seconds.

<!-- CSS CDN -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/Suman-11-web/SUI-FRAMEWORK.CSS@v2.0.0/dist/sui.min.css">

<!-- Optional JS CDN (for animations/interactions) -->
<script src="https://cdn.jsdelivr.net/gh/Suman-11-web/SUI-FRAMEWORK.CSS@v2.0.0/dist/sui.min.js"></script>

<!-- Usage -->
<button class="sui-btn sui-btn-primary">
  Hello SUI.css
</button>
